The RSF-BGC pipeline and sample--anchor bipartite-graph learning structure. The multi-view input data $\mathbf{X}^{(p)}$ is reconstructed jointly with the sample-sparse residual $\mathbf{D}^{(p)}$ and projected into a latent space via the orthogonal basis $\mathbf{U}^{(p)}$. The objective couples local anchor-aware quadratic regularization ($\lambda_3 \|\mathbf{Z}^{(p)}\|_\eta^2$) with the alignment penalty ($\lambda_1 \|\mathbf{Z}^{(p)}-\mathbf{R}^{(p)}\mathbf{H}\|_F^2$). At iteration $t$, the retained consensus target $\mathbf{C}^{(p,t-1)}=\mathbf{R}^{(p,t-1)}\mathbf{H}^{(t-1)}$ enters the graph update for $\mathbf{Z}^{(p,t)}$, and the revised graph then updates $\mathbf{R}^{(p,t)}$ and $\mathbf{H}^{(t)}$ to form the next target. The resulting $\mathbf{C}^{(p,t-1)}\!\rightarrow\!\mathbf{Z}^{(p,t)}\!\rightarrow\!\mathbf{C}^{(p,t)}$ update is the central design choice.
